--------------------------------------------------------------------------
HOW TO USE THIS FILE
--------------------------------------------------------------------------

Fill it in with your own content and hand it, together with template.html, to
an LLM: "build my CV from this text using this template". The structure above
maps onto the template one-to-one:

  name + role line       ->  <h1> and <p class="role"> in the header
  section headings       ->  <h2> in the sidebar or main column
  job title/company/city ->  <h3> inside a <div class="job">
  date line              ->  <p class="when">
  intro paragraph        ->  <p class="intro">
  "Group label:"         ->  <p class="group">
  bullet lines           ->  <li>

Then run ./render.sh.

Doing it by hand works too — the template is plain HTML and the classes above
are all there is to learn.

Two things worth deciding rather than defaulting:

  - Ordering. The template assumes reverse chronological. If your most recent
    entry is a career break, personal projects or study, it still goes first;
    it is the most recent thing you did.

  - Dates. Keep the format identical in every entry. Mixed formats are the
    fastest way to make a CV look assembled rather than written.
